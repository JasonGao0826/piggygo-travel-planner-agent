# 小猪游记 PiggyGo

<img src="apps/web/public/brand/logo.png" alt="小猪游记 PiggyGo" width="160">

**交给猪猪，你负责开心出发！**

帮在澳留学生规划新西兰、澳洲旅行的 AI 助手"猪猪"：填一份信息清单生成整份行程，之后用对话反复修改，所有改动都要过校验、经用户确认才生效，随时导出可编辑的 Word 报告。

设计见 [docs/设计规格.md](docs/设计规格.md)。

## 目录

| 目录 | 内容 |
|---|---|
| `services/api` | 后端（Python）：数据结构、校验器、记忆层、agent、首次生成、凭证识别、Word 报告、外部数据（MCP、路况、天气）、FastAPI 接口。说明见 [services/api/README.md](services/api/README.md) |
| `apps/web` | 网页（Next.js）。说明见 [apps/web/README.md](apps/web/README.md) |
| `data/kb` | 景点知识库（经官网核实）、机场和城镇 |
| `data/routing` | 人工校准的车程表 |
| `data/demo` | 新西兰演示行程 |
| `packages/schema` | 数据结构和接口的 JSON Schema / OpenAPI，供网页使用 |
| `tests/eval` | 回放测试数据 |
| `docs` | 设计规格、上线指南 |

## 本地运行

第一次需要装依赖，见两个子目录的 README。

**一键启动**：双击仓库根目录的 `启动.bat`。它会在两个窗口里分别启动后端和网页（已经在运行的会跳过），都就绪后自动打开浏览器。要停止，关掉「后端」和「网页」两个窗口即可。

**手动启动**（Windows PowerShell，一行一行运行），开两个终端：

后端：

```powershell
cd E:\旅行规划助手agent\services\api
.\.venv\Scripts\python.exe -m uvicorn tripagent.api.main:app --port 8765
```

网页：

```powershell
cd E:\旅行规划助手agent\apps\web
npm run dev
```

然后打开 http://localhost:3000 。模型的 API key 放在 `services/api/.env`（参考 `.env.example`），不进 git。

本地开发不用登录，页面上的「我是」可以切换成任何成员，方便测试。

## 上线

放在 Render（新加坡）上，接自己的域名，每人用专属邀请链接登录。要注册的账号、买域名、接域名、发链接的每一步见 [docs/上线指南.md](docs/上线指南.md)。

相关文件：`Dockerfile`、`render.yaml`、`scripts/docker-start.sh`、`services/api/requirements.txt`。

## 多人一起商量

行程页的「大家」页签（设计规格第 13 节）：

- **每人填自己的偏好**：必玩、想去、不想玩、节奏、开车时长、预算、饮食。上线后每人用自己的专属链接打开，就是本人身份；本地开发时用「我是」切换。在对话里说出自己的偏好，助手也会记下。
- **意见汇总**：发起人点「现在汇总」，列出共识、分歧和可以分组的项目；必玩项目写进决策账本。
- **投票**：从分歧一键发起，大家投完自动出结果并写进决策账本，平票由发起人拍板；再点「让助手按结果调整」。
- **动态**：「动态」页签里能看到谁确认了改动、上传了凭证、改了偏好、投了票。

## 账本（AA 记账和结算）

行程页的「账本」页签：谁付了什么都记在一起，自动算出谁该给谁多少钱。

- **记一笔**：网页上填，或者直接跟猪猪说"晚饭我付了 NZ$128，天哥没吃"（会生成草稿，确认后入账）。上传有金额的凭证也会顺带生成草稿。
- **多币种**：填银行卡实际扣的澳币最准；还没出账先按央行汇率暂估，出账后补填；现金按当天汇率。
- **结算**：转账次数最少的方案，一键复制发到微信群；情侣可以合并成一方结算；转账后标"已转"，收款人确认收到才算。
- **导出**：账目可以导出 Excel（CSV），Word 报告和行程包里也有。

## 出发前清单

- 每天时间表开头写着当天要带什么（护照、驾照翻译件、泳衣毛巾、防风外套……）。
- Word 报告里有"出发前清单"：证件、钱、手机、保险、衣物、药品，打勾用。
- 订好了但还缺细节的（门牌号、入住时间、床型、停车、入住方式、租车保险），「待办」页签一键变成确认待办。

## 小红书攻略

在「大家」→「我的偏好」里贴小红书链接（或整段分享文字），猪猪读出提到的地点、价格、预约建议和注意事项，一键加进想去或必玩；读不到就上传笔记截图。对话里直接贴链接也行。攻略只当参考，价格和营业时间以官网为准。

## 凭证夹和行程包

行程页的「凭证」页签：谁订好了机票、住宿、租车、门票，就把确认单传上来，所有人都能看、能下载。

- **上传并识别**：猪猪读出时间和确认号，和行程比对、锁定对应安排。
- **只存档**：门票二维码、入场票这类只需要出示的文件，直接存，不花时间。
- **下载行程包**：右上角「下载」→「行程包」，一个压缩包里有 Word 报告、日历文件和全部凭证（按日期命名），出行时离线也能打开。

## 外部数据

不用额外配置就能用（设计规格第 22 节）：

- **机票**：对话里让助手查航班，或者生成行程时自动给还没订的航班找 3 个真实候选（Kiwi.com）。
- **汇率、网页搜索**：助手换算金额、核实营业时间和步道关闭时自动使用。
- **实时情况**：行程页的「实时情况」面板显示路况、天气预警、天气预报和公众假日对行程的影响。出发前 10 天起后台每 15 分钟刷新，每条提醒都可以点「让助手调整」。
- **导出日历**：行程页右上角「导出日历」，导入手机日历后每个安排都有提醒。
- **邮件凭证**：「上传凭证」可以直接选确认邮件（.eml）。

接入的外部服务列在 `services/api/mcp_servers.yaml`，只开放里面列出的只读工具。
